About the project

Monitoring the environment, one sensor at a time.

Environmental Monitoring using Sensors and Data Analysis — modeled after real-world Community Engagement Project monitoring work.

Air Quality

PM2.5 particulate matter and carbon monoxide (CO), benchmarked against NAAQS thresholds.

Water Quality

pH, turbidity, total dissolved solids (TDS), and dissolved oxygen, benchmarked against BIS drinking-water guidelines.

Noise Levels

Ambient sound level in decibels, flagged when readings exceed safe thresholds.

NAAQS benchmarks BIS drinking-water guidelines Low-cost sensors Real-time analysis ESP32-ready
Data shown on the dashboard is currently simulated for demonstration purposes. The backend is built with a swappable data source — it can be switched to accept real readings from Wi-Fi-connected hardware (e.g. an ESP32 with actual sensors) without changing the frontend.
